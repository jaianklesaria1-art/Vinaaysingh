- **Bluorng**, bluorng.com: premium Indian streetwear. Shows delivery and returns upfront (5 to 11 day delivery, 5-day returns).

## UX rules to keep, whatever the animation
1. **Mobile first.** Most buyers will be on phones, so animations must stay smooth there or switch off.
2. **Animation never blocks buying:** no long intro loaders, and the add-to-bag button is always reachable.
3. **Product pages:** big images, zoom, a size guide with real measurements, fit notes ("model is 6'0", wears M"), delivery date, and returns shown before checkout.
4. **Respect "reduce motion"** settings, and keep pages fast. Heavy WebGL only on one hero moment, not everywhere.
5. **Drops and scarcity done honestly:** "limited run of 200" only if it's true.
